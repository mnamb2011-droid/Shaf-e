# الموسوعة الشافعية الشاملة | The Comprehensive Shafi'i Fiqh Encyclopedia

تطبيق أندرويد محلي بالكامل (**Offline-First**) مكتوب بلغة **Kotlin** وواجهة **Jetpack Compose (Material 3)** مع دعم كامل للغة العربية واتجاه **RTL**، مدعوم بقاعدة بيانات **SQLite + FTS5** مفصولة عن كود التطبيق وقابلة للتحديث والاستيراد الجزئي، وقاعدة بيانات **Room** مستقلة لبيانات المستخدم (المفضلة، الملاحظات، سجل القراءة والبحث).

---

## 1. المنهجية العلمية وسياسة التوثيق
- **عدم الاختلاق القطعي**: لا يُنسب قول ولا يُثبت رقم صفحة أو إجماع إلا عند التحقق؛ وما لم يثبت فيه نص موثق يُصرح فيه بعبارة: `لم يثبت لدينا نص موثق`.
- **ست درجات للتحقق التحريري**:
  1. `موثق من المصدر الأصلي`
  2. `موثق من مصدر ناقل معتبر`
  3. `نسبة مشهورة تحتاج مقابلة`
  4. `مختلف في نسبته`
  5. `يحتاج مراجعة`
  6. `غير متحقق`
- **التمييز الصارم بين الطبقات**: يفرّق التطبيق برمجياً وبصرياً بين القول القديم، والقول الجديد، وأقوال الأصحاب والأوجه والطرق، واتفاق الشيخين (الرافعي والنووي)، ومعتمد المتأخرين (ابن حجر والرملي والشربيني)، والاجتهادات والبحوث المعاصرة.

---

## 2. بنية قاعدة البيانات ومسار التوسعة (Stages 1–4)
- **الحجم الفعلي لقاعدة البيانات التأسيسية (Stage 1)**:
  - قاعدة البيانات غير المضغوطة (`database/shafii_encyclopedia.db`): **384.0 KB**
  - الحزمة المضغوطة المدمجة في التطبيق (`app/src/main/assets/db/shafii_encyclopedia.db.gz`): **57.2 KB**
- **محتوى المرحلة الأولى (Stage 1 — تم بناؤه والتحقق منه)**:
  - جميع الكتب الفقهية الـ **17** التقليدية + **37** باباً هرمياً قابلاً للطي والتوسيع.
  - **6** طبقات تاريخية + **20** عالماً من أعلام المذهب (من الإمام الشافعي إلى الرملي وابن حجر).
  - **18** مصدراً شافعياً أساسياً + **7** طبعات موثقة + **2** سجل مخطوطات + **14** مصطلحاً من مصطلحات المذهب والمنهاج.
  - **12** مسألة فقهية تأسيسية محررة (بما فيها أبرز المسائل المفتى بها على القديم، والفرق بين اختيار النووي والمعتمد، ونازلة معاصرة مفصولة منهجياً)، تضم **43** قولاً، **30** توثيق مصدر، **16** دليلاً، **4** نصوص مقتبسة، و**8** روابط بين المسائل.
- **مسار استيراد حزم التوسعة (`database/import_pack.py`)**:
  ```bash
  python3 database/import_pack.py database/sample_expansion_pack.json database/shafii_encyclopedia.db
  python3 database/verify_database.py database/shafii_encyclopedia.db
  ```
  ثم يمكن للمستخدم استيراد ملف `shafii_encyclopedia.db.gz` مباشرة من داخل التطبيق (الإعدادات ← استيراد حزمة قاعدة بيانات) دون فقدان مفضلته أو ملاحظاته.

## 3. بناء ملف APK عبر GitHub Actions (تلقائياً دون الحاجة لـ Android Studio)
1. ارفع محتويات هذا المشروع إلى مستودع GitHub جديد (تأكد من بقاء مجلد `.github/workflows/build-apk.yml` في الجذر).
2. افتح تبويب **Actions** وشغّل سير العمل **Build Shafi'i Fiqh Encyclopedia APK** (أو يعمل تلقائياً عند كل Push على `main`).
3. سيقوم السيرفر تلقائياً بـ:
   - إعادة بناء وفحص قاعدة البيانات واختبارات FTS5.
   - تشغيل اختبارات Kotlin (`ArabicNormalizerTest`).
   - بناء ملفات `app-debug.apk` و`app-release.apk` (مضغوط بـ R8) وإظهار أحجام الـ APK وقاعدة البيانات بشكل منفصل.
4. حمّل الـ APK الجاهز للتثبيت من قسم **Artifacts**.

## 4. البناء المحلي في Android Studio
1. افتح مجلد `ShafiiFiqhEncyclopedia` في **Android Studio Ladybug (2024.2+)** مع **JDK 17** و**Android SDK 35**.
2. نفّذ:
   ```bash
   gradle testDebugUnitTest assembleRelease
   ```
3. يعمل التطبيق على **Android 8.0 (API 26)** فأحدث دون أي صلاحية إنترنت (`No INTERNET permission`).
